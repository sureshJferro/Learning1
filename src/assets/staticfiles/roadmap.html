Angular Developer Roadmap (Concept-Wise)

🟢 Beginner Level: Angular Fundamentals

1. HTML, CSS, and JavaScript (Pre-requisite)
  • Semantic HTML: Use meaningful tags like <header>, <nav>, <article>, etc.
  • CSS Flexbox & Grid: Used for creating responsive layouts.
  • JavaScript ES6+ Features: let/const, arrow functions, promises, etc.
  • DOM Manipulation: Using JS to interact with HTML elements.

// JavaScript ES6+ Example
const greet = (name) => `Hello, ${name}`;
console.log(greet("Angular Dev")); // Output: Hello, Angular Dev
2. TypeScript
  • Types: Static typing with number, string, boolean, etc.
  • Interfaces & Enums: Custom types and enums for constants.
  • Classes & Access Modifiers: OOP features in TypeScript.
  • Generics: Reusable components with flexible types.
  • Decorators: Meta-programming syntax used in Angular.

// TypeScript Interface Example
interface User {
  name: string;
  age: number;
}

const user: User = { name: "John", age: 30 };

🟡 Intermediate Level: Angular Core Concepts

3. Angular Setup & Architecture
  • Installing Angular CLI: npm install -g @angular/cli
  • Creating a Project: ng new my-app
  • Folder Structure: src/app contains all components, services, modules, etc.
  • Modules and Components: Modular structure with reusability and separation of concerns.

// Example: Creating a component
ng generate component my-component

// app.module.ts example
import { NgModule } from '@angular/core';
import { BrowserModule } from '@angular/platform-browser';
import { AppComponent } from './app.component';

@NgModule({
  declarations: [AppComponent],
  imports: [BrowserModule],
  bootstrap: [AppComponent]
})
export class AppModule {}
4. Components
  • Component Creation: Use CLI: ng generate component
  • Component Metadata: Decorated with @Component to define selector, template, and style.
  • Template and Styles: Inline or external files for HTML and CSS.
  • Lifecycle Hooks: ngOnInit, ngOnDestroy, etc., used to manage component state and side effects.

// my-component.component.ts
import { Component, OnInit, OnDestroy } from '@angular/core';

@Component({
  selector: 'app-my-component',
  template: '
Hello from MyComponent
',
  styles: ['h2 { color: green; }']
})
export class MyComponent implements OnInit, OnDestroy {
  ngOnInit() {
    console.log('Component initialized');
  }

  ngOnDestroy() {
    console.log('Component destroyed');
  }
}
5. Data Binding
  • Interpolation ({{ }})
    Used to display dynamic data in templates.
    <h1>Welcome {{ username }}!</h1>
  • Property Binding ([property])
    Binds DOM element property to component property.
    <img [src]="imageUrl" />
  • Event Binding ((event))
    Responds to user actions.
    <button (click)="handleClick()">Click</button>
  • Two-way Binding ([(ngModel)])
    Combines property and event binding for form inputs (requires FormsModule).
    <input [(ngModel)]="name" />
6. Directives
  • Built-in Directives:
    *ngIf, *ngFor, [ngClass], [ngStyle]
    *ngIf: <p *ngIf="isLoggedIn">Welcome back!</p>
      *ngFor: <li *ngFor="let item of items">{{ item }}</li>
      [ngClass]: <div [ngClass]="{'active': isActive}"></div>
      [ngStyle]: <div [ngStyle]="{'color': textColor}"></div>
  • Attribute vs Structural Directives
    - Attribute directives modify element appearance/behavior (e.g., [ngClass]).
    - Structural directives change the DOM layout (e.g., *ngIf, *ngFor).
  • Creating custom directives
    Example: HighlightDirective
    @Directive({
        selector: '[appHighlight]'
      })
      export class HighlightDirective {
        constructor(el: ElementRef) {
          el.nativeElement.style.backgroundColor = 'yellow';
        }
      }
7. Component Communication
  • @Input() and @Output()
    - @Input() passes data from parent to child.
    - @Output() sends events from child to parent. 
    Parent: <child [data]="parentData" (notify)="onNotify()"></child>
      
      Child:
      @Input() data: string;
      @Output() notify = new EventEmitter();
  • EventEmitter
    Used with @Output() to emit custom events.
    this.notify.emit('Data from child');
  • ViewChild and ContentChild
    - @ViewChild accesses child component/directive in template.
    - @ContentChild accesses projected content.
    @ViewChild(ChildComponent) childComp!: ChildComponent;
      ngAfterViewInit() {
        console.log(this.childComp.someMethod());
      }
  • Shared Service for communication
    Best for sibling component communication.
    service.sendMessage('Hello');
      service.message$.subscribe(msg => this.received = msg);
8. Services and Dependency Injection
  • Creating and injecting services
    Generate with Angular CLI: ng generate service my-service
    Inject in constructor:
    constructor(private myService: MyService) {}
  • Using @Injectable()
    Marks a class as injectable and available to be used in DI system.
    @Injectable({
        providedIn: 'root'
      })
      export class MyService {}
  • Hierarchical injectors
    - Services provided in AppModule are singleton.
    - Services provided in components have limited scope to that component and its children.
